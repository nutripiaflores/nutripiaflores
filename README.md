# Pía Flores — Nutricionista

Landing page estática responsive para presentar la atención nutricional online y a domicilio y facilitar el contacto por WhatsApp.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: identidad visual, diseño responsive y estilos.
- `script.js`: menú móvil y año automático.
- `assets/logo-pia-flores.png`: logotipo corporativo suministrado.

## Publicar en Render
Crear un Static Site conectado al repositorio de GitHub y configurar:
- Build Command: dejar vacío.
- Publish Directory: `.` (raíz del repositorio).
- Branch: `main` (o la rama que corresponda).

Render entregará una dirección pública `onrender.com`. Se puede conectar un dominio propio después.

## Antes de publicar
Revisar:
- Nombre y datos profesionales.
- Redacción exacta de certificaciones, especialmente la línea de obesidad/enfermedades metabólicas, que aparece cortada en la imagen del CV recibida.
- Comunas de cobertura para atención a domicilio.
- Si se desea añadir correo profesional, redes sociales, fotografía y/o dirección.
